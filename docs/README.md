## Quick Reference

### Key Platform Features

- **Smart Medical Search**: Autocomplete TB terminology with fuzzy matching
- **Clinical Decision Support**: AI-powered treatment recommendations
- **Advanced Analytics**: Resistance trend analysis and visualization
- **Global Collaboration**: Secure data sharing and research opportunities
- **Real-time Dashboard**: Key metrics and interactive visualizations
- **Data Management**: Import/export capabilities with validation

### Technical Stack

- **Frontend**: Streamlit with modern CSS styling
- **Backend**: Python with modular architecture
- **Database**: PostgreSQL with comprehensive schema
- **Analytics**: Plotly visualizations, pandas processing
- **Search**: FuzzyWuzzy with Levenshtein distance
- **Security**: SHA-256 hashing, role-based access control

### Default Credentials

- **Username**: admin
- **Password**: admin123

### API Access

- **Base URL**: `/api/v1/`
- **Authentication**: Bearer token
- **Rate Limit**: 1000 requests/hour
